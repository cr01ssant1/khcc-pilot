# KHCC Pilot

Keymer & Hassocks Cricket Club (est. 1896).

Pilot website for the cricket club. Plain HTML/CSS/JS – no build step.

- `index.html` – page content
- `css/styles.css` – styling (green & gold colours are defined at the top)
- `js/main.js` – fixtures & results data (edit the lists at the top), menu and form behaviour

To preview locally, open `index.html` in a browser.
